# 如意设计 · Ruyi Design

小爱好 / LittleHobby 出品。品牌承诺：让设计，更合心意。

产品服务于 UI/UX 交互原型的预览、评论和反复改进。展示名称使用“如意设计”，英文使用“Ruyi Design”；技术接入名称见[迁移表](migration-to-ruyi-design.md)。公司署名使用“小爱好出品”或“By LittleHobby”。包作用域固定为小写 `littlehobby`，界面不展示 MCP 或 npm 后缀。

## 标志

最终标志采用提交墙方印：七行绿色方格填充圆角方印，叠加白色如意。五档绿度体现持续雕琢的积累感，24px 及以下减弱背景纹理。方印图案来自用户确认版本 `f1a705f1`，透明与紧裁适配随最终工作区版本 `6c0bfd72` 批准。资产位于 `src/browser/assets/`，构建后位于 `dist/workspace/`：

- `ruyi-mark.svg`：按方印边界紧裁的透明符号（viewBox 为 `5 5 54 54`），兼作 SVG favicon；界面推荐 24–40px。
- `ruyi-mark-mono.svg`：同一方印和如意镂空轮廓的单色适配，内联时跟随 `currentColor`；用于单色印刷，不是另一套候选标志。
- `ruyi-wordmark.svg`：如意设计 / Ruyi Design 组合字标；推荐宽度 176px，窄屏切换符号。

符号资产不内置外围留白或白色底板，圆角外透明，favicon 直接使用紧裁符号。界面中的外部间距由所在控件布局控制；不向图标文件添加空白，不拉伸、不加渐变或阴影。浅色与深色背景均应保持可识别。SVG 使用本地系统字体栈，不请求远程字体。可访问名称为“如意设计 · Ruyi Design”；窄屏符号仍有“如意设计”替代文字。

## 令牌和使用

`src/browser/styles/brand.css` 按基础 → 语义 → 控件分层。组件消费语义令牌，桥接覆盖层消费 `src/contracts/brand.ts` 中相同的品牌颜色。

| 用途 | 色值 |
| --- | --- |
| 玉绿主色、普通定位、成功 | `#2F6B58` |
| 悬停 | `#255644` |
| 选中浅底 | `#E8F0E9` |
| 暖白画布 / 白色面板 | `#F7F5EF` / `#FFFFFF` |
| 主文字 / 次文字 | `#263C32` / `#647267` |
| 木色署名 | `#8E603E` |
| 控件边界 | `#7B8E80` |
| 错误 / 删除定位 | `#A33A36` / `#96600F` |
| 历史横幅文字 / 底色 | `#78500B` / `#FFF8E6` |

正文对比度至少 4.5:1，必要控件边界和焦点至少 3:1。普通定位为玉绿实线；删除定位为琥珀虚线，伴随“此处已删除”。历史页面有文字横幅与返回按钮。状态不能仅通过颜色表达。木色只用于署名等装饰。

字体使用系统无衬线，正文 14px，说明 12–13px，标题 20px；空间以 4px 为基准，控件圆角 8px、面板 12px。键盘焦点为 3px 玉绿轮廓，尊重减少动效设置。

工具品牌只作用于工作区和桥接定位层。消费者设计稿在隔离 iframe 中保留自己的品牌、令牌与逻辑设备尺寸；Northstar 示例不更换品牌或令牌。页面导航支持平铺与可折叠层级，父页面名称打开自身页面，独立箭头展开/收起；设备和状态在页面内选择，组件直接比较全部适用状态。

当前仅有一个正式标志，其他云头、字母环、双叶和赛博候选已从当前资产中移除。不可变评审快照保留设计历史。

工作区品牌位于左侧菜单底部：左侧标志，右侧上方“如意设计”、下方纯文字连接状态胶囊。胶囊替换英文副标题，不含图标、圆点或其他符号，不设置品牌上方的独立状态行；连接中、已连接、修改中、重连、失败均保留明确文字和可访问状态语义。英文品牌名称继续用于产品标题、CLI 和分发文档。页面选中、悬停高亮包裹整行图标与标题，根级图文与设计系统入口对齐。
