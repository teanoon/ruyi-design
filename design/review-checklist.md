## 快捷键验收

| 操作 | 预期 |
| --- | --- |
| 在内层工具空白区按 C / Shift+C | 进入/退出内层预览，按钮及画布文案同步 |
| 在内层空白区按 ← / → | 按设备列表顺序切换，只访问有效设备，首尾不循环 |
| 在内层空白区按 ↑ / ↓ | 按页面状态列表顺序切换，优先保留设备，否则回退至有效设备 |
| 首页：手机 → 空内容 | 回退桌面；空内容只有桌面，左右键无效 |
| 品牌故事：桌面 → 阅读模式 | 回退手机；阅读模式只有手机 |
| 评论输入、联系与到访的表单、原生下拉框 | C 和方向键保留输入/控件自身行为；Ctrl/Cmd+Enter 仍可保存评论 |
| 预览模式中，焦点在示例页面 | C 可退出预览，方向键留给页面；外壳空白区仍可切换组合 |
| 设计系统 → 按钮等组件 | 全部适用状态一起展示；左右键切换设备，不出现顶层状态菜单 |
| 设计系统 → 设计令牌 | 不响应设备/状态切换；鼠标仍可导航 |
| 查看原版本 | 预览按钮禁用，C 不绕过禁用；可返回最新版 |
| 输入法组合输入、Ctrl/Meta/Alt、长按重复 | 不触发工作区快捷键 |
| 未保存评论时切换组合或预览 | 输入仍保留，保存时仍对应原评论上下文 |

## 层级页面导航验收

本次导航沿用既有品牌、画布与评审分区。以下清单同时用于产品原型和实际工作区：

| 验收项 | 预期 |
| --- | --- |
| 父节点名称 / 独立文件夹图标 | 名称打开父页面，文件夹只展开/收起；不新增“概览” |
| 图标与整行高亮 | 收起/展开文件夹和单页三种图标；选中/悬停包裹图标与名称，根级图文对齐设计系统 |
| 直接展开入口 | 首页下级页面展开状态支持桌面/手机，不依赖保存的折叠偏好 |
| 收起当前页祖先 | 画布、URL、评论草稿保持不变，祖先提示内部有当前页 |
| 纯分组 | 名称与箭头只折叠，不产生页面目标 |
| 搜索 | 保留匹配页面及祖先，匹配分组可见其后代；清空恢复原展开状态 |
| 展开记忆 | 多分组独立记忆；刷新时定位当前页；禁用存储仍可使用 |
| 键盘 | Tab、Enter、Space 可操作；导航方向键不误切换状态/设备 |
| 桌面与窄屏 | 长名称可换行，层级和操作可识别，无横向溢出 |
| 评论、链接与版本定位 | 清除查询、展开目标祖先；历史版本使用自身目录 |
| 身份与旧项目 | 移动目录不改变页面 ID 或评论；旧清单继续平铺 |

原型使用 3 个模拟页面，真实工作区验收生成 10 个父页面各 5 个子页面（共 60 页）。两者复用同一导航控件、搜索和展开逻辑。真实版本、URL 历史、评论定位及快照由运行时测试覆盖；原型保留既有模拟评审数据及状态，不冒充真实 session。
