# 如意设计 · 产品设计稿

这里评审的是如意设计自身的产品界面；`examples/starter/design/` 的 Northstar 是独立消费者 demo，资产、评论和历史不混用。

当前批准版本为 `6c0bfd72-fec4-4c32-972c-6c604b2cee24`。用户已确认“设计审核通过”，并在重启后确认“重启后功能/设计正常”。完整验收和实际数据差异见 [review-checklist.md](review-checklist.md)。

## 工作区与导航

设计稿包含元素评论、添加/原位编辑、交互预览、新版待复核及首页子页面展开状态；评论、归档和原版本查看都在工作区内完成。工具外壳不展示示例项目名称，画布内“山野拾光”仅用于模拟体验。

页面导航支持父页面与纯分组。点击“首页”名称打开自身页面，文件夹图标独立展开“品牌故事”；“到访管理”为纯分组，包含“联系与到访”。关闭文件夹、打开文件夹和单页图标区分三种节点；选中与悬停高亮覆盖整行，根级图文与设计系统入口对齐。搜索保留祖先路径，展开偏好由浏览器本地记忆；目录操作不重建画布。

“首页下级页面展开”提供 desktop/mobile 独立入口；内层首页也可选择“下级页面展开”。进入该状态确定性展开子页面，不依赖此前操作或本地折叠偏好。

## 品牌与状态

侧栏底部左侧为提交墙方印，右侧上方为“如意设计”，下方是纯文字状态胶囊，替换英文副标题；无独立状态行、图标或状态点。标准/单色标志紧裁至方印边界，去掉外围白底，圆角外透明。方印图案来源 `f1a705f1` 保留，其他候选不再出现在当前设计中，历史快照不改写。

导航和连接胶囊共用 `components/page-navigation.js`、`page-navigation.css` 与 `connection-status.css`；原型以原生 ES module 使用，实际工作区通过 Vite 打包复用。

## 评论与快捷键

评论按创建时间倒序。只有精确选择同一元素才激活已有评论，父子元素不互相复用；同一元素复用已有讨论（包括已解决/归档），多个需求写在正文或回复中；旧重复记录保留但不能新增。取消编辑保留原文，确认解决不改变当前标签；卡片不再提供手动归档。用户追加回复默认重新打开并显示在进行中，原文、定位和历史保留；处理中的追加内容在发布后留给下一轮，固定输入不变。

C 切换预览，左右键切换有效设备，上下键切换页面状态，首尾不循环。输入、原生选择控件与导航控件保留自身键盘行为；中文组合输入不打断。元素评论模式在 pointerdown 阶段阻止原型抢焦点，预览模式保留表单交互；Ctrl/Cmd+Enter 保存评论。原版本不能进入预览。

操作内层原型时先开启外层预览。内层已处理的按键不重复触发外层。组件直接总览全部适用状态，高度自适应，页面保持设备逻辑视口；令牌单独展示。

## 启动与评审

HTML/CSS/JS 无需构建，页面复用共享组件。模拟评论不写入真实评审数据；对设计稿本身的意见请保存在外层工具。

```bash
npm run build
npm run test:design
RUYI_DESIGN_HOST=0.0.0.0 RUYI_DESIGN_PORT=4173 RUYI_DESIGN_PREVIEW_PORT=4174 RUYI_DESIGN_BASE_URL='https://design.dev.test:34000/?port=4173' npm run preview:design
```

通过 MCP 启动时，显式传入绝对 `projectRoot`、`designRoot: <仓库>/design`、`dataRoot: <仓库>/.ruyi-design` 及网关配置；与 demo 的 `.uxai-review/` 隔离。存在多套数据时不要合并或移动旧历史。

保存评论不自动启动 AI。在对话中说“我已评论，可以更新”后才固定并处理本轮输入，发布后由用户复核。MCP 与工作区监听处于同一 Node 进程；构建后如需加载新后端，应重启 MCP 进程，再恢复同一 dataRoot 的工作区。只调用 end/start_review 不重新加载后端模块；刷新浏览器用于载入新版外壳。

## 评论操作精简（simplify-comment-actions）

设计稿 `7d1ee1a1-2db4-4e99-81e6-c739d7b76a04` 已获用户“审核通过”。实际工具按该版本实现，运行时验收结果记录在变更 validation.md。适用操作全部展开，不使用更多菜单；待复核为定位、查看原版本（不同版本时）、回复、确认解决、重新打开。移除新增评论、归档/无需处理按钮，同一元素打开已有讨论，已解决/归档只读打开不会重开。回复自动重开，活动批次回复保留为下一轮；撤销重开保留线程。

工作区新增评论已纳入更新、处理中、待澄清、重新打开、有历史的待处理、已解决、历史归档、查看原版本、旧重复评论和删除元素原版本对照状态，可在外层状态控件切换。评论卡片组件同时展示全部状态。外层如意用于评审，体验内层交互时先开启外层预览。
