# Northstar Starter

一个可以独立运行、也可以通过 如意设计 · Ruyi Design 评审的团队协作原型。所有数据均为本地示例；登录、发送邮件、保存资料和创建项目用于体验交互，不连接真实后端。

原型位于 `design/`，由共享的 CSS 令牌和 JavaScript 组件组成，无需构建、无远程字体或图片依赖。

| 页面     | 可直接进入的状态                       | 设备             |
| -------- | -------------------------------------- | ---------------- |
| 登录     | 默认、输入错误、登录中                 | Desktop / Mobile |
| 工作台   | 有内容、空数据、加载中、加载失败       | Desktop / Mobile |
| 项目详情 | 项目概览、项目动态                     | Desktop / Mobile |
| 设置     | 个人资料、输入错误、保存成功、通知偏好 | Desktop / Mobile |

设计系统包含 17 个令牌，以及按钮、输入框、状态标签、项目卡片、创建项目弹窗。组件展示按设备排列所有适用状态；触屏设备不包含悬停状态。

## 在本项目中评审

本仓库的 `.codex/config.toml` 已配置 `ruyi_design`，项目技能位于 `.agents/skills/ruyi-design-review/`。重新加载 Codex 的 MCP 连接后发送：

> 使用 ruyi-design-review，启动本项目 examples/starter/design 的评审站点，给我预览链接。

保存评论后，在对话中发送：

> 我已评论，可以更新设计稿。

页面无需提交，智能体不会持续监听；每次只处理你主动要求的一轮，之后新增的评论留待下一次通知。

工具参数应使用当前仓库的绝对 `projectRoot` 与 `examples/starter/design` 的绝对 `designRoot`。本仓库继续原地使用既有 `.uxai-review/`；新项目默认使用 `.ruyi-design/`，均与设计资产分开。

## 值得体验的交互

- 登录：提交空表单、错误邮箱，再输入有效邮箱和任意非空密码进入工作台；忘记密码可打开找回弹窗。
- 工作台：按状态筛选或搜索项目，切换任务完成状态，打开通知提示。
- 创建项目：点击新建，提交空名称检查错误，再填写名称；项目会加入当前页面，不污染下一次直接打开的初始状态。
- 项目详情：从卡片进入，切换概览与动态，并勾选项目任务。
- 设置：检查邮箱错误，保存资料并显示成功反馈；通知分类可修改偏好。
- 所有状态都通过入口查询参数初始化，例如 `pages/home.html?state=empty`，无需按特定顺序点击。

## 复用与恢复

`components/` 提供共用实现，`pages/` 负责布局与页面状态，`showcases/` 使用同一组件构造函数。`tokens/tokens.css` 与清单中的令牌值保持一致。可评论元素使用稳定的 `data-review-id`。

工作台、项目详情和设置提供可序列化状态恢复接口。界面改版后可恢复选中页签、任务、筛选和弹窗；安全表单字段由工作区桥接恢复，密码不采集。创建的项目仅在当前体验会话内有效。

## 检查

在仓库根目录运行：

```bash
node dist/cli/index.js doctor --design examples/starter/design
node tests/browser/starter.mjs
```

浏览器检查覆盖全部清单入口、桌面/移动布局及关键交互，并将截图保存到 `test-results/starter/`。
